

##  Catchub – Landing Page (HTML & CSS)

A landing page design for **Catchub**, built using **pure HTML and CSS**.
This project focuses on clean layout, proper structure, and basic front-end best practices.

---

## Features

* Fully static landing page
* Clean and modern UI design
* Two-column layout using **Flexbox**
* Organized sections:

  * Hero Section
  * Channels
  * Messages
  * Future
  * Footer
* Uses images for app previews and store buttons
* Beginner-friendly and easy to understand code

---

##  Technologies Used

* **HTML5**
* **CSS3 (Flexbox)**
* No frameworks or libraries used

---

##  Learning Objectives

* Practice HTML semantic structure
* Understand Flexbox layouts
* Improve CSS positioning & spacing
* Work with images and assets
* Build confidence in static web design
