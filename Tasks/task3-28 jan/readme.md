#  Submission Form UI

A modern **Submission Form UI** built using **HTML5** and **CSS3**.
This project demonstrates a clean layout and modern design techniques such as **Flexbox** and **CSS clip-path**.

---

##  Features

* Clean and professional UI design
* Two-column layout (Left info section + Right form section)
* Custom polygon background using `clip-path`
* Fully styled inputs, textareas, and checkboxes
* Modern submit button with icon
* Simple and readable code structure

---

## Technologies Used

* **HTML5**
* **CSS3**
* **Flexbox**
* **Clip-path**
* **Responsive Design Basics**
