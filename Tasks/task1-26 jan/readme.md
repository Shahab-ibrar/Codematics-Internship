# Task1 – Semantic Web Page Layout

## Overview

This repository contains **Task1**, completed as part of the **Codematics Internship Program**.
The objective of this task was to implement a basic web page layout using **semantic HTML5 elements** and **CSS Flexbox**, strictly following the given constraints and reference design.

The layout includes a header, navigation section, a three-column main content area, and a footer.

## Implementation Details

The page is built entirely with **semantic HTML elements** to ensure clarity, accessibility, and proper structure:

* `header` defines the top section of the page.
* `nav` represents the navigation area.
* `main` serves as the primary layout container.
* Two `aside` elements are used for left and right supporting content.
* `section` contains the main content.
* `footer` appears at the bottom of the layout.

CSS **Flexbox** is applied to the `main` element to align the content horizontally.
The central section uses flexible sizing, while the side sections maintain fixed widths.
Styling is kept minimal and is used only for layout, spacing, and alignment.
