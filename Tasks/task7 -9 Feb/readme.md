

# JavaScript Utility Tasks Collection

A structured collection of **beginner-to-intermediate JavaScript utility programs** built using **HTML, CSS, and Vanilla JavaScript**.
This project demonstrates practical understanding of **core JavaScript concepts**, **DOM manipulation**, and **event-driven programming**.

## Tasks

### 1. Age to Days Converter

* Accepts user input via a **calendar (date input)**.
* Calculates age in **total days** using JavaScript `Date` objects.
* Demonstrates time-based calculations.

---

### 2. Hours to Seconds Converter

* Converts hours into seconds using a standard formula.
* Includes basic input validation.
* Demonstrates arithmetic operations.

---

### 3. Find the Next Number

#### Scenario A: Array-Based Search

* Searches a predefined array:
  `[10, 20, 30, 40, 50]`
* Identifies and returns the **next value** in the array.

#### Scenario B: User Input-Based Logic

* Determines whether input is an **integer or float**.
* Logic applied:

  * Integer → increment by `1`
  * Float → increment by `0.1`
* Demonstrates type checking and conditional logic.

---

### 4. Name Capitalization Utility

* Accepts a lowercase name.
* Capitalizes the **first letter only**.
* Demonstrates string manipulation techniques.

---

### 5. BMI (Body Mass Index) Calculator

* Takes weight (kg) and height (meters) as input.
* Calculates BMI using the standard formula:

  ```
  BMI = weight / (height × height)
  ```
* Displays formatted BMI value.

---

### 6. Random Array Generator

* Generates an array of random numbers dynamically.
* Displays:

  * Complete array
  * First element
  * Last element
* Demonstrates loops and array indexing.

---

### 7. Real-Time Addition Using Event Handling

* Uses **three input fields**:

  * Two for numbers
  * One for displaying result
* Implements **event listeners** (`input` events).
* Shows `NaN` when inputs are incomplete.
* Demonstrates event-driven programming.
