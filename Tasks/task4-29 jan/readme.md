Red Card 2018 – China Digital Football Awards

This project is a static web page developed using HTML5 and CSS3.
It is based on the “Red Card 2018 – China Digital Football Awards” design and was created to practice layout structuring, image handling, and modern CSS techniques while closely matching a given reference design.

Key Features

* Structured header section with logo and descriptive content
* Reusable “Best Clubs” sections built using Flexbox
* Proper usage of image assets instead of text-based badges
* Clean typography and spacing aligned with the reference layout
* Styled footer with centered content and a custom clipped shape
