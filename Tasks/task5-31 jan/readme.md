# Keefer Law Firm Website (HTML & CSS)

This project is a **static website clone** of the Keefer Law Firm homepage, built using **pure HTML, CSS, and a small amount of JavaScript**.
It focuses on **layout accuracy, responsiveness, and clean UI structure**.

---
## Project Features

* Fully responsive layout (Desktop, Tablet, Mobile)
* Flexbox & CSS Grid based layout
* Professional navigation bar
* Hero section with form
* Info cards & practice areas
* Right sidebar with call-to-action buttons
* Pixel-aligned UI similar to original design
* Clean and readable code structure

---

## Technologies Used

* **HTML5**
* **CSS3**

  * Flexbox
  * Grid
  * Media Queries
* **JavaScript**

  * Mobile navigation toggle
* **No frameworks** (No Bootstrap, No Tailwind)
