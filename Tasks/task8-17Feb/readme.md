# 🚀 JavaScript Task 8 – Multi-Feature Web App

A modern **JavaScript practice project** that combines multiple interactive components in a single responsive web application using **HTML, Tailwind CSS, and Vanilla JavaScript**.

This project demonstrates core front-end development concepts such as DOM manipulation, event handling, local storage, and UI interactions.

---

## 📌 Features

The application includes the following tools:

### 🎞️ Image Carousel

* Smooth sliding transition
* Next / Previous navigation buttons
* Responsive design

### 🧮 Calculator

* Basic arithmetic operations (+, −, ×, ÷)
* Input validation
* Error handling

### ⏰ Digital Clock

* Real-time clock with seconds
* 12-hour format with AM/PM indicator

### 🌡️ Temperature Converter

* Celsius to Fahrenheit conversion
* Fahrenheit to Celsius conversion
* Rounded results with 2 decimal precision

### 🔐 Password Generator

* Custom password options:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Symbols
* Copy to clipboard functionality

### ✅ Todo List

* Add, edit, delete tasks
* Mark tasks as completed
* Persistent storage using **LocalStorage**
